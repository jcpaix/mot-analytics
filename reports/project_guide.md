# 이 사이트는 무엇을 하는 곳인가요?

기업의 긴 사업보고서와 기술 논문을 한곳에 모아, 어떤 일을 하는 기업인지와 어떤 기술이 연구되고 있는지를 비교하는 도구입니다. 데이터 분석을 몰라도 분야를 고르고 그래프·표·원문을 차례로 볼 수 있게 만들었습니다.

## 왜 만들었나요?

기업마다 사업보고서의 형식과 설명이 다르고, 논문도 양이 많아 처음부터 모두 읽기는 어렵습니다. 자사와 같은 분야의 기업을 비교하고, 관심 기술의 연구 내용을 살펴볼 때 먼저 읽을 자료를 찾도록 돕기 위해 만들었습니다. 기업의 사업 설명, 매출·영업이익, 기술 논문을 함께 보여주며 모든 결과에서 출처로 돌아갈 수 있게 했습니다.

## 무엇을 얼마나 분석했나요?

기업은 한국거래소 KIND의 2025년 결산 사업보고서 22개를 사용합니다. 반도체 10개, IT·플랫폼·게임 4개, 자동차·부품 4개, 바이오·제약 4개입니다. 공개 원문과 주된 사업을 확인해 선정한 표본이며 모든 상장기업을 조사한 것은 아닙니다. 산업 분야는 사람이 지정한 분류입니다.

기업의 사업 설명은 보고서의 ‘II. 사업의 내용’을 가져왔습니다. 주요 제품·서비스, 판매, 연구개발 등 해당 절 전체를 읽을 수 있습니다. 매출과 영업이익은 ‘III. 재무에 관한 사항’의 요약재무정보에서 별도로 가져왔습니다. 22개 기업의 2023~2025년 실적을 확인했으며, 틸론의 2023년 연결 요약 수치는 해당 공시에 없어 비워 둡니다. 금액을 억원으로 통일하고 연결·별도 기준과 원문 근거를 표시합니다.

논문은 OpenAlex에서 찾되 arXiv 원문 링크와 초록이 있는 자료만 사용합니다. 반도체·AI 하드웨어, AI·소프트웨어, 자동차·자율주행, 바이오·의료 AI 네 분야에 각 120편씩, 분야별 표본 합계 480편입니다. 분야 사이에 같은 논문이 포함될 수 있어 480편이 모두 서로 다른 논문이라는 뜻은 아닙니다. 분석하는 글은 제목과 초록이며 PDF 전체가 아닙니다.

각 논문 분야는 2025년 1~8월과 2026년 1~8월에서 최신순 60편씩 비교합니다. OpenAlex의 출판일을 기준으로 하며 arXiv에 처음 올라온 날짜와 다를 수 있습니다. 자료는 2026년 9월 13일에 수집했습니다. 검색 조건과 문서별 수집 시각, 원문 링크를 데이터와 수집 기록에서 확인할 수 있습니다.

## 어떤 순서로 만들었나요?

1. 자료 수집: 기업명과 결산일을 확인한 KIND 사업보고서, 검색 조건에 맞는 OpenAlex 논문 정보를 가져왔습니다. 요청이 실패하면 가상의 자료로 채우지 않았습니다.
2. 내용 정리: 사업 설명과 재무를 구분하고, 원문 제목·문단·표를 정리했습니다. 금액의 원래 단위와 연도, 연결·별도 기준을 확인했습니다.
3. 단어 분석: 자주 반복되는 공시 표현과 ‘따라’, ‘있으며’ 같은 불필요한 표현을 제외하고 단어의 중요도를 계산했습니다. 한국어 형태소 분석을 사용하지 않아 일부 어미·조사 표현이 남을 수 있습니다.
4. 같은 분야 비교: 기업 유사도와 지도는 같은 산업 분야의 기업끼리 계산합니다. ‘전체 분야’를 선택하더라도 유사도를 계산할 산업은 따로 고릅니다.
5. 화면 구성: 기업 수, 재무 그래프, 단어 비교, 지도, 기업별 원문 토글, 출처와 수집 기록을 넣었습니다. 워드클라우드는 사용하지 않습니다.
6. 검증과 공개: 데이터 파일의 해시를 수집 기록과 대조하고, 기업 분야와 논문 분야별 화면을 확인했습니다. GitHub에는 프로그램·데이터·설명을 보관하고, 공개 웹에서는 결과와 자료를 쉽게 탐색할 수 있게 했습니다.

## 어려운 분석 용어를 쉽게 설명하면

TF-IDF는 ‘이 글에서 두드러지는 표현’을 찾는 점수입니다. 모든 글에 흔한 표현은 점수를 낮추고 특정 글에서 자주 쓰는 표현은 높입니다. 단어가 중요하다고 해서 그 제품의 매출이 가장 크다는 뜻은 아닙니다. 실제 주력 사업은 제품·서비스 설명과 실적을 함께 읽어 확인해야 합니다.

유사도는 두 글이 비슷한 표현을 얼마나 비슷한 비중으로 쓰는지 나타냅니다. 0에서 1 사이이며 1에 가까울수록 글의 표현이 비슷합니다. 두 기업이 실제 경쟁사인지, 어느 기업이 우수한지 판단하는 점수는 아닙니다.

자동 군집은 단어 점수가 비슷한 글끼리 만든 묶음입니다. KMeans라는 방법으로 묶음의 중심과 각 글 사이의 거리를 줄이도록 나눕니다. 묶음 수를 바꾸면 결과도 달라집니다. 사람이 지정한 산업 분야와 자동 묶음은 서로 다른 기준입니다.

지도는 수천 개 단어 점수를 SVD라는 방법으로 두 축에 압축해 그린 그림입니다. 가까운 점은 표현이 비슷한지 살펴볼 후보입니다. 압축하면서 정보가 줄어들기 때문에 지도만 보지 말고 유사도 수치와 원문을 확인해야 합니다.

논문의 단어 변화는 각 기간의 논문 중 그 단어를 한 번 이상 쓴 논문의 비율 차이입니다. 예를 들어 이전 20%, 최근 30%라면 변화는 +10%p입니다. 한 논문에서 같은 단어를 여러 번 썼다고 여러 편으로 세지 않습니다. 제한된 최신순 표본이므로 전체 연구량이나 시장 성장률로 해석할 수 없습니다.

## 그래프와 표는 어떻게 읽나요?

기업 수는 이 프로젝트가 분석한 표본의 크기입니다. 산업 전체의 기업 수가 아닙니다. 분야별 기업 수가 다르므로 합계만으로 어느 분야가 더 활발한지 판단하지 않습니다.

매출은 기업이 제품·서비스를 팔아 벌어들인 금액입니다. 영업이익은 주요 영업에서 수익과 비용을 계산한 이익이며 음수이면 영업손실입니다. ‘연결’은 종속회사를 포함하고 ‘별도’는 해당 법인만 집계합니다. 같은 기업의 연도 변화를 먼저 보고 같은 분야 기업의 금액과 기준을 비교하세요. 기업별 작은 그래프는 세로축 범위가 다르므로 서로의 선 높이를 그대로 비교하면 안 됩니다.

분야별 단어 색상 표는 기업별 단어 점수의 분야 평균입니다. 색이 진할수록 해당 표현의 평균 중요도가 높습니다. 시장 규모나 매출 비율을 나타내는 표가 아닙니다.

원문에 여러 통화나 단위가 섞인 금액은 원래 열과 단위를 유지한 표로 보여줍니다. 소제목을 누르면 내용이 열리고, 검색창으로 원하는 항목을 찾을 수 있습니다.

## 처음 쓰는 사람에게 권하는 순서

1. 관심 산업 분야를 고르고 분석한 기업 수와 목록을 확인합니다.
2. 자사와 비교할 기업의 매출·영업이익과 연결·별도 기준을 확인합니다.
3. 기업별 원문에서 주요 제품·서비스와 연구개발 내용을 읽습니다.
4. 같은 분야 기업의 유사도와 지도에서 공통 표현과 차이를 확인합니다.
5. 기술 논문 화면에서 관심 분야를 고르고 두 기간의 단어 비율과 대표 초록을 읽습니다.
6. 궁금한 수치나 문장은 원문 출처 링크로 직접 확인합니다.

## 어떤 기술로 만들었나요?

자료 수집·표 정리·분석은 Python으로 작성했습니다. pandas로 표를 다루고 scikit-learn으로 단어 점수·유사도·묶음·지도를 계산했습니다. Plotly로 확대하고 값을 확인할 수 있는 그래프를 만들었습니다. 로컬 앱은 Streamlit으로 구성했습니다.

공개 웹 화면은 같은 데이터와 Python 분석 결과를 웹용 파일로 내보내 브라우저에서 분야·기업·묶음 수를 선택해 보도록 구성했습니다. 현재 수집한 자료를 공개한 것으로 실시간으로 새로운 공시나 논문을 자동 수집하지 않습니다. 자료를 갱신하려면 다시 수집·검증·분석한 뒤 웹 화면을 배포합니다. 공개 화면은 조회용이며 직접 수집·CSV 업로드는 로컬 Streamlit 앱에서 할 수 있습니다.

## 결과를 믿기 전에 확인할 점

선정한 기업과 논문 표본의 결과이며 전체 산업이나 전체 연구를 대표하지 않습니다. 보고서는 특정 제출본을 사용하므로 최신 정정 여부는 원문에서 확인해야 합니다. 재무 수치는 공시의 반올림·재작성·연결 범위를 따르며 코다코의 감사 의견거절도 함께 표시합니다. 자동 군집과 지도는 글을 탐색하는 보조 도구입니다. 최종 비교는 원문과 실적 기준을 함께 확인하세요.
